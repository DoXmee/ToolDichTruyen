TOOLDICHTRUYEN - CÀI ĐẶT / CẬP NHẬT MÁY MỚI
===============================================

1. Giải nén TOÀN BỘ file ZIP vào một thư mục bất kỳ.
2. Bấm đúp: CAI-DAT-CAP-NHAT-TOOLDICHTRUYEN.cmd
3. Chờ thông báo “Hoàn tất”. Sau đó bấm đúp biểu tượng ToolDichTruyen trên Desktop để mở app.

LƯU Ý QUAN TRỌNG
----------------
- Không chạy ToolDichTruyen.exe trực tiếp bên trong thư mục ZIP đã giải nén.
- File cài đặt sẽ đóng app, XÓA thư mục app cũ do ToolDichTruyen quản lý, rồi chép bản mới sạch vào:
  %LOCALAPPDATA%\Programs\ToolDichTruyen
- Bản dịch, checkpoint, prompt và cấu hình được giữ trong:
  %APPDATA%\tool-dich-truyen
  Chúng KHÔNG bị xóa khi cập nhật app.
- Desktop chỉ có shortcut ToolDichTruyen.lnk. Toàn bộ thư mục app không bị đưa ra Desktop.
- Tên người dùng hoặc đường dẫn Desktop có dấu tiếng Việt vẫn được hỗ trợ khi tạo shortcut.
- Bộ cài xóa shortcut cũ, dùng file logo mới có tên theo phiên bản và yêu cầu Windows làm mới bộ nhớ đệm biểu tượng.

CÀI TIỆN ÍCH HULIWANG
---------------------
1. Mở edge://extensions, chrome://extensions hoặc coccoc://extensions.
2. Bật Developer mode → Load unpacked.
3. Chọn thư mục ngay cạnh file cài đặt có tên “EXTENSION-HULIWANG - CHON THU MUC NAY”.
4. Trong app, bấm Kết nối trình duyệt mặc định khi cần đọc Huliwang.

Nếu trình duyệt đã từng cài tiện ích cũ, vào trang extensions và bấm Reload tiện ích sau khi cập nhật.
